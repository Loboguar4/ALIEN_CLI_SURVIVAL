## 📖 Visão geral

**Alien: CLI Survival** é um jogo single-player baseado em texto, projetado para criar tensão e imersão usando apenas o terminal como interface.

O jogador assume o papel de um tripulante isolado em uma nave espacial avariada, enfrentando falhas sistêmicas, eventos imprevisíveis e organismos hostis enquanto aguarda um possível resgate.

O projeto foi desenvolvido como um **exercício técnico, narrativo e educacional**, explorando design de jogos, lógica procedural e narrativa ambiental.

## 🎮 Mecânicas principais

- 🗺️ Exploração em mapa com sensores de movimento  
- ⏱️ Contagem regressiva até o resgate  
- ⚡ Gerenciamento de energia da nave  
- 🛠️ Sistemas críticos:
  - Energia
  - Pilotagem
  - Comunicações
  - Saúde
  - Carga
- 👾 Inimigos com movimentação dinâmica
- 🎒 Inventário com recursos limitados
- 🚨 Eventos aleatórios críticos
- 🧠 Narrativa ambiental via logs e terminais

A sobrevivência depende mais de **decisão e estratégia** do que de reflexos.
